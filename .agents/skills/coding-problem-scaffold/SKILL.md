# 코딩 문제 파일 생성

사용자가 전달한 코딩 문제 URL에 접속해 현재 프로젝트 루트에 풀이 파일을 만든다.

## 생성 절차

1. 페이지에서 플랫폼명과 문제 제목을 확인한다. 플랫폼명은 사이트의 공식 한글 이름을 우선한다. 예를 들어 `school.programmers.co.kr`은 `프로그래머스`로 사용한다.
2. 대상 경로를 `<프로젝트 루트>/<플랫폼>/<문제 제목>`으로 정한다.
3. 대상 폴더의 존재 여부를 쓰기 전에 확인한다. 이미 존재하면 해당 경로가 존재한다고 안내하고 즉시 중단한다. 기존 폴더나 파일을 읽어 고치거나 덮어쓰지 않는다.
4. 폴더가 없으면 생성하고 아래 세 파일만 만든다.

## `문제.js`

- 페이지에서 제공하는 JavaScript 기본 풀이 코드를 그대로 시작점으로 사용한다.
- 입출력 예의 각 입력 행을 기본 함수 호출 인수로 변환해 파일 끝에 `console.log(...)`를 하나씩 추가한다.
- 출력 예시는 `console.log`에 넣지 않는다.
- 인수 순서는 문제에서 정의한 함수 매개변수 순서를 따른다.
- 형식은 프로젝트의 `프로그래머스/완주하지 못한 선수/문제.js`를 참고한다.

예시:

```js
function solution(participant, completion) {
    var answer = '';
    return answer;
}

console.log(solution(["leo", "kiki", "eden"], ["eden", "kiki"]));
```

## `문제.md`

파일 맨 위에 다음 front matter를 둔다. `level` 값은 사용자가 직접 입력하도록 비워 둔다.

```md
---
title: <문제 제목>
link: <사용자가 전달한 원본 URL>
level:
---
```

- 페이지에 있는 문제 설명, 제한사항, 입출력 예, 입출력 예 설명을 빠짐없이 추출한다.
- 제목, 목록, 표, 인라인 코드 등 적절한 마크다운 문법으로 정리한다.
- 문제 내용이나 예시 값을 임의로 바꾸거나 풀이를 추가하지 않는다.
- 형식은 프로젝트의 `프로그래머스/완주하지 못한 선수/문제.md`를 참고한다.

## `설명.md`

내용이 없는 0바이트 파일로 생성한다. 제목, 공백, 줄바꿈도 넣지 않는다.

## 완료 확인

생성 후 세 파일이 모두 존재하는지 확인하고 생성한 폴더 경로만 간단히 안내한다.
