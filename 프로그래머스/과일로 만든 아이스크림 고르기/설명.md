# 내 풀이

## 접근

두 테이블에 공통으로 존재하는 `FLAVOR`를 기준으로 `JOIN`한다. 조인한 결과에서 총주문량이 3,000보다 많고 주 성분이 과일인 행만 남긴 뒤, 총주문량을 기준으로 내림차순 정렬한다.

```sql
SELECT F.FLAVOR FROM ICECREAM_INFO AS I JOIN FIRST_HALF AS F ON I.FLAVOR = F.FLAVOR WHERE F.TOTAL_ORDER > 3000 AND I.INGREDIENT_TYPE = "fruit_based" ORDER BY F.TOTAL_ORDER DESC
```

예시에서는 총주문량 조건을 만족하는 과일 아이스크림이 `strawberry`와 `melon`이다. `melon`의 총주문량이 3,150으로 `strawberry`의 3,100보다 많으므로 `melon`, `strawberry` 순서로 조회된다.

## 풀이 과정

1. `ICECREAM_INFO`를 `I`, `FIRST_HALF`를 `F`라는 별칭으로 사용한다.
2. `I.FLAVOR = F.FLAVOR`가 같은 행을 연결해 성분 타입과 총주문량을 함께 조회할 수 있게 한다.
3. `F.TOTAL_ORDER > 3000`으로 총주문량이 3,000보다 많은 행만 남긴다.
4. `I.INGREDIENT_TYPE = "fruit_based"`로 주 성분이 과일인 행만 남긴다.
5. `ORDER BY F.TOTAL_ORDER DESC`로 총주문량이 많은 순서대로 정렬한다.
6. `SELECT F.FLAVOR`로 아이스크림 맛만 반환한다.

## 개선점

문자열은 SQL 표준에 맞게 큰따옴표보다 작은따옴표로 작성하는 편이 안전하다. 즉, `"fruit_based"`를 `'fruit_based'`로 표현할 수 있다.
