# 내 풀이

```js
function solution(s){
    const stack = [];
    for (const e of s) {
        if (e === ')') {
            const stackItem = stack.pop();
            if (!stackItem) return false;
        }

        if (e === '(') {
            stack.push(e);
        }
    }
    return stack.length === 0;
}
```

## 접근

여는 괄호 `(`를 스택에 넣고, 닫는 괄호 `)`를 만나면 스택에서 하나 꺼냅니다. 꺼낼 값이 없으면 닫을 괄호가 먼저 나온 경우이므로 즉시 `false`를 반환합니다.

## 풀이 과정

`"(())()"`를 순회하면 `(` 두 개가 `stack`에 쌓입니다. 이어지는 `)` 두 개가 각각 하나씩 꺼내고, 마지막 `()`도 같은 방식으로 처리되어 스택이 비게 됩니다. 따라서 `true`를 반환합니다.

반대로 `")()("`는 첫 글자 `)`에서 `pop()`할 값이 없으므로 바로 `false`를 반환합니다. 순회가 끝난 뒤에도 스택에 `(`가 남아 있으면 닫히지 않은 괄호가 있다는 뜻이므로 `false`입니다.

## 복잡도

- 시간 복잡도: `O(n)` — 문자열을 한 번 순회합니다.
- 공간 복잡도: `O(n)` — 모두 `(`인 경우 스택에 최대 `n`개가 쌓입니다.

# 다른 사람의 풀이

```js
function solution(s){
    let cum = 0
    for (let paren of s) {
        cum += paren === '('? 1: -1
        if(cum < 0) {
            return false
        }
    }
    return cum === 0? true: false;
}
```

## 코드 해석

`cum`은 아직 닫히지 않은 `(`의 개수입니다. `(`이면 `1`을 더하고, `)`이면 `1`을 뺍니다. 값이 음수가 되면 닫는 괄호가 먼저 나온 것이므로 즉시 `false`를 반환합니다. 끝까지 순회한 뒤 `cum`이 `0`이면 모든 괄호가 짝지어진 상태입니다.

## 내 풀이와의 차이

두 풀이는 모두 닫는 괄호가 먼저 나왔는지 중간에 확인하고, 마지막에 남은 여는 괄호가 없는지 확인한다는 핵심이 같습니다. 내 풀이는 실제 `(`를 스택에 저장하고, 다른 사람 풀이는 개수만 저장합니다. 이 문제는 괄호 종류가 하나뿐이라 개수만으로 충분하므로 다른 사람 풀이는 공간을 `O(1)`만 사용합니다.

## 한 줄로 정리

스택을 직접 구현한 내 풀이를, 스택의 크기만 남긴 `cum` 풀이로 더 작게 표현한 코드입니다.
