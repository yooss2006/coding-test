# 완주하지 못한 선수 풀이

## 접근 방법

처음에는 완주자 이름을 `participant`에서 하나씩 찾아 제거하는 방법을 생각했다. 하지만 `findIndex`와 `splice`는 배열의 길이에 비례하는 시간이 걸린다. 참가자가 최대 100,000명이므로 이 방법은 최악의 경우 `O(n²)`이 되어 시간 초과가 발생한다.

두 배열을 정렬하면 같은 이름이 같은 위치에 나란히 놓인다. 따라서 앞에서부터 이름을 비교했을 때 처음으로 값이 다른 위치의 참가자가 완주하지 못한 선수다.

## 풀이 과정

1. `participant`와 `completion`을 각각 정렬한다.
2. 인덱스 0부터 두 배열의 이름을 비교한다.
3. 이름이 같으면 다음 인덱스로 이동한다.
4. 이름이 처음 달라지는 순간 `participant[index]`를 반환한다.

예를 들어 다음 두 배열을 정렬하면 미완주자를 바로 찾을 수 있다.

```text
participant: ["ana", "mislav", "mislav", "stanko"]
completion:  ["ana", "mislav", "stanko"]
                                  ^
```

인덱스 2에서 `"mislav"`와 `"stanko"`가 처음으로 다르므로 `"mislav"`가 완주하지 못한 선수다. 이름을 정렬해 비교하므로 동명이인이 있어도 같은 방식으로 찾을 수 있다.

미완주자가 정렬된 `participant`의 마지막에 있다면, 해당 인덱스의 `completion` 값은 `undefined`다. 두 값이 다르므로 반복문이 종료되고 마지막 참가자를 반환한다.

## 다른 사람의 풀이
### `Map`으로 인원수 차이를 기록한 풀이

```javascript
function solution(participant, completion) {
    const map = new Map();

    for (let i = 0; i < participant.length; i++) {
        const a = participant[i];
        const b = completion[i];

        map.set(a, (map.get(a) || 0) + 1);
        map.set(b, (map.get(b) || 0) - 1);
    }

    for (const [name, count] of map) {
        if (count > 0) return name;
    }

    return "nothing";
}
```

참가자는 이름별 인원수를 1만큼 더하고, 완주자는 1만큼 뺀다. 완주한 선수의 값은 최종적으로 0이 된다. 완주하지 못한 선수만 1이 남으므로 `count > 0`인 이름을 반환한다.
