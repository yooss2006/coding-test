# 내 풀이

```js
function solution(clothes) {
    const clothesMap = new Map();
    clothes.forEach(([name, type]) => {
        clothesMap.set(type, [...(clothesMap.get(type) || []), name]);
    });

    return [...clothesMap.values()]
    .reduce((total, items) => total * (items.length + 1), 1) - 1;
}
```

## 접근

`Map`을 사용해 의상을 종류별로 묶는다.

한 종류에 의상이 `n`개 있다면 선택지는 의상 `n`개와 아무것도 입지 않는 경우를 합친 `n + 1`개다. 종류별 선택은 서로 독립적이므로 각 종류의 선택지 수를 모두 곱한다.

모든 종류에서 아무것도 입지 않는 경우는 문제 조건에 맞지 않으므로 마지막에 `1`을 뺀다.

첫 번째 예시에서 `headgear`의 선택지는 3개이고 `eyewear`의 선택지는 2개다. 따라서 가능한 조합은 `3 × 2 - 1 = 5`개다.

## 풀이 과정

1. 빈 `Map`인 `clothesMap`을 만든다.
2. `clothes`를 순회하며 각 의상을 `[name, type]`으로 구조 분해한다.
3. 같은 `type`의 기존 배열을 가져와 현재 `name`을 추가한다. 기존 배열이 없으면 빈 배열에서 시작한다.
4. `clothesMap.values()`로 종류별 의상 배열을 가져온다.
5. `reduce`의 초깃값을 `1`로 두고, 각 배열의 길이에 `1`을 더한 값을 차례로 곱한다.
6. 아무 의상도 선택하지 않은 한 가지 경우를 제외하기 위해 결과에서 `1`을 뺀다.
