# 내 풀이

## 접근

`FIRST_HALF`의 모든 행에서 `FLAVOR`만 조회한다. 먼저 `TOTAL_ORDER`를 기준으로 내림차순 정렬하고, 총주문량이 같으면 `SHIPMENT_ID`를 기준으로 오름차순 정렬한다.

예시에서 `white_chocolate`와 `strawberry`의 `TOTAL_ORDER`는 모두 3100이다. 이때 `SHIPMENT_ID`가 105인 `white_chocolate`가 109인 `strawberry`보다 먼저 나온다.

```sql
SELECT FLAVOR FROM FIRST_HALF ORDER BY TOTAL_ORDER DESC, SHIPMENT_ID ASC
```

## 풀이 과정

1. `FROM FIRST_HALF`로 상반기 주문 정보를 조회한다.
2. `ORDER BY TOTAL_ORDER DESC`로 총주문량이 많은 행부터 정렬한다.
3. 총주문량이 같은 행은 `SHIPMENT_ID ASC`로 출하 번호가 작은 행부터 정렬한다.
4. `SELECT FLAVOR`로 정렬된 행의 아이스크림 맛만 반환한다.
