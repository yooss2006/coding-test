# 내 풀이

## 접근

전화번호를 문자열 기준으로 정렬하면 비슷한 번호끼리 모인다.

예를 들어 다음 배열은

```text
["119", "97674223", "1195524421"]
```

정렬 후 다음과 같이 바뀐다.

```text
["119", "1195524421", "97674223"]
```

어떤 번호가 다른 번호의 접두어라면 두 번호도 정렬 후 서로 이웃하게 된다. 따라서 모든 번호를 서로 비교하지 않고, 현재 번호와 바로 다음 번호만 비교하면 된다.

## 풀이 과정

1. `phone_book.sort()`로 전화번호를 사전순으로 정렬한다.
2. 첫 번째 번호부터 마지막 번호의 바로 앞까지 순회한다.
3. `startsWith()`로 다음 번호가 현재 번호로 시작하는지 확인한다.
4. 접두어인 번호를 발견하면 `answer`를 `false`로 바꾼다.
5. 모든 비교가 끝나면 `answer`를 반환한다.

```javascript
function solution(phone_book) {
    var answer = true;
    phone_book.sort();

    for (let i = 0; i < phone_book.length - 1; i++) {
        if (phone_book[i + 1].startsWith(phone_book[i])) {
            answer = false;
        }
    }

    return answer;
}
```

현재 코드는 접두어를 발견한 뒤에도 남은 번호를 계속 확인한다. 접두어를 발견하는 즉시 `false`를 반환하면 불필요한 비교를 줄일 수 있다.

## 복잡도

- 시간 복잡도: 정렬에 `O(n log n)`, 순회에 `O(n)`이 필요하므로 전체 시간 복잡도는 `O(n log n)`이다.
- 공간 복잡도: 정렬 구현에서 사용하는 추가 공간을 제외하면 `O(1)`이다.

# 다른 사람의 풀이

```javascript
function solution(phoneBook) {
    return !phoneBook.sort().some((t, i) => {
        if (i === phoneBook.length - 1) return false;

        return phoneBook[i + 1].startsWith(phoneBook[i]);
    });
}
```

## 코드 해석

### `phoneBook.sort()`

전화번호를 사전순으로 정렬한다. 접두어 관계인 번호를 서로 이웃하게 만들기 위한 과정이다.

### `.some((t, i) => { ... })`

`some()`은 배열을 순회하며 콜백 함수가 한 번이라도 `true`를 반환하면 즉시 순회를 멈추고 `true`를 반환한다.

이 코드에서는 다음 번호가 현재 번호로 시작하는 순간 `true`가 된다.

```javascript
phoneBook[i + 1].startsWith(phoneBook[i])
```

즉, `some()`의 결과는 다음과 같다.

- 접두어인 번호가 있으면 `true`
- 접두어인 번호가 없으면 `false`

콜백의 첫 번째 매개변수 `t`는 현재 전화번호지만 코드에서 사용하지 않는다. 두 번째 매개변수 `i`만 현재 인덱스로 사용한다.

### 마지막 인덱스 검사

```javascript
if (i === phoneBook.length - 1) return false;
```

마지막 번호에는 비교할 다음 번호가 없다. `phoneBook[i + 1]`에 접근하지 않도록 `false`를 반환해 해당 비교를 건너뛴다.

### 앞의 `!`

문제가 요구하는 반환값은 `some()`의 결과와 반대다.

- 접두어인 번호가 있으면 `some()`은 `true`지만 정답은 `false`다.
- 접두어인 번호가 없으면 `some()`은 `false`지만 정답은 `true`다.

따라서 앞에 논리 부정 연산자 `!`를 붙여 결과를 뒤집는다.

## 한 줄로 정리

내 풀이는 `for`문으로 모든 이웃을 확인해 결과를 저장하고, 다른 사람의 풀이는 `some()`으로 접두어를 발견하는 즉시 순회를 끝낸다.
