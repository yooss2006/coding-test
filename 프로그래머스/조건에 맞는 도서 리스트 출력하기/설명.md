# 내 풀이

## 접근

`PUBLISHED_DATE`가 `2021-01-01` 이상이고 `2022-01-01` 미만인 도서만 남겨 2021년에 출판된 도서를 찾는다. 여기에 `CATEGORY = '인문'` 조건을 함께 적용하고, 출판일 오름차순으로 정렬한다.

```sql
SELECT BOOK_ID, PUBLISHED_DATE
FROM BOOK
WHERE PUBLISHED_DATE >= '2021-01-01'
  AND PUBLISHED_DATE < '2022-01-01'
  AND CATEGORY = '인문'
ORDER BY PUBLISHED_DATE ASC
```

## 풀이 과정

1. `FROM BOOK`으로 도서 정보를 조회한다.
2. `PUBLISHED_DATE >= '2021-01-01'`과 `PUBLISHED_DATE < '2022-01-01'`으로 2021년 출판 도서만 선택한다. `2021-12-31`까지 직접 비교하지 않아도 되므로 날짜 범위를 정확하게 표현할 수 있다.
3. `CATEGORY = '인문'`으로 인문 카테고리만 남긴다.
4. `SELECT BOOK_ID, PUBLISHED_DATE`로 필요한 두 컬럼만 반환한다.
5. `ORDER BY PUBLISHED_DATE ASC`로 출판일이 빠른 도서부터 정렬한다.
