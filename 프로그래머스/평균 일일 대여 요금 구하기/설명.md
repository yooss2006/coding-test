# 접근

`WHERE` 절로 자동차 종류가 `SUV`인 행만 남긴다. 필터링된 행의 `DAILY_FEE` 평균을 `AVG`로 구하고, `ROUND`를 사용해 소수 첫 번째 자리에서 반올림한다.

```sql
SELECT ROUND(AVG(DAILY_FEE), 0) AS AVERAGE_FEE
FROM CAR_RENTAL_COMPANY_CAR
WHERE CAR_TYPE = 'SUV'
```

## 쿼리 해석

1. `FROM CAR_RENTAL_COMPANY_CAR`로 자동차 정보 테이블을 조회한다.
2. `WHERE CAR_TYPE = 'SUV'`로 SUV인 자동차만 선택한다.
3. `AVG(DAILY_FEE)`로 선택된 자동차들의 일일 대여 요금 평균을 계산한다.
4. `ROUND(..., 0)`으로 평균을 소수점 이하 0자리까지 반올림한다.
5. `AS AVERAGE_FEE`로 결과 컬럼명을 지정한다.
