# 폰켓몬 풀이

## 핵심 아이디어

N/2마리를 고를 때 얻을 수 있는 종류 수는 두 값 중 작은 값입니다.
- 고를 수 있는 폰켓몬 수: `nums.length / 2`
- 전체 폰켓몬 종류 수: `new Set(nums).size`

종류가 N/2개 이상이면 서로 다른 종류만 골라 N/2종류를 얻을 수 있습니다. 종류가 N/2개보다 적으면 모든 종류를 하나씩 골라도 그 종류 수를 넘을 수 없습니다.

따라서 두 값의 최솟값을 반환합니다.

```javascript
const n = nums.length / 2;
const uniqueItemsSize = new Set(nums).size;

return uniqueItemsSize >= n ? n : uniqueItemsSize;
```

## 예시

`nums = [3, 3, 3, 2, 2, 4]`이면 3마리를 골라야 합니다.

- 고를 수 있는 수: `6 / 2 = 3`
- 종류 수: `{3, 2, 4}`이므로 `3`

두 값의 최솟값은 `3`입니다.
